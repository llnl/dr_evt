# Bindings API

The Python extension exposes selected [`Simulation`][cpp-simulation], [`Sim_Params`][cpp-sim-params], policy,
streaming, and monitoring APIs through pybind11.

See the [Python API reference](../../PYTHON_API.md) and
[`python/dr_evt_bindings.cpp`](https://github.com/LLNL/dr_evt/blob/main/python/dr_evt_bindings.cpp).
