# Scheduling and Backfill API

`SchedulerBase`, the FCFS/SJF/LJF schedulers, wait queues, and schedule
windows implement priority ordering and EASY or conservative backfilling.

Browse the generated [src/sim API](../source/sim.rst). See
[Wait Queues](../../../dev/WAIT_QUEUES.md) and
[Backfilling Algorithms](../../../BACKFILLING_ALGORITHMS.md) for the
implementation and algorithm guides.
