Simulator API
=============

`Simulation <cpp-simulation_>`_ coordinates trace initialization, job submission, event-time
advancement, scheduling, statistics, and output generation.

.. if-doxygen::

   `Simulation <cpp-simulation_>`_ is the standard-trace alias
   `BasicSimulation<Trace> <cpp-basicsimulation_>`_.
