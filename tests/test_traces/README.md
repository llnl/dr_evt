# Test Traces

This directory contains input fixtures and expected outputs used by the DR_EVT
test runners. The authoritative category inventory and commands are in the
[Test Suite README](../README.md).

The `scheduler_correctness/` directory has its own
[fixture index](scheduler_correctness/README.md). Input and output schemas are
documented in
[Input Trace Files](../../docs/user-guide/trace-formats.md) and
[Output Trace Files](../../docs/user-guide/output-traces.md).
