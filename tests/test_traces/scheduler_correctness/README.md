# Scheduler Correctness Fixtures

This directory contains the small FCFS/EASY workloads used to compare DR_EVT
with the Python reference scheduler. Each fixture may include:

- `<name>.csv`: input workload;
- `<name>.expected_output.csv`: expected scheduled-job trace;
- `<name>.expected_resources.csv`: expected resource-usage trace;
- `<name>.answer.json`: structured schedule constraints; and
- `<name>.construction.md`: a human-readable derivation of the scenario.

Expected CSV files are generated by the independent Python implementation,
then checked by `tests/run_scheduler_correctness_tests.sh`. Agreement is a
cross-implementation consistency check; the validation model and its limits
are described in the [Testing Guide](../../../docs/TESTING_GUIDE.md).

Test counts, commands, and instructions for adding fixtures are maintained in
the [Test Suite README](../../README.md). Input and output columns are defined
in [Input Trace Files](../../../docs/user-guide/trace-formats.md) and
[Output Trace Files](../../../docs/user-guide/output-traces.md).
