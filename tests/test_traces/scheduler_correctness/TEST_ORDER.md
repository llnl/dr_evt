# Scheduler Correctness Fixture Order

The numbered fixture names provide a stable identifier; their numeric order is
not a required execution or learning sequence. Each `.construction.md` file
describes the behavior exercised by that fixture.

For test commands, category counts, and contribution instructions, see the
[Test Suite README](../../README.md). For scheduler semantics, see
