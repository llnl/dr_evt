# Historical names

Recorded JSON and logs retain the API names and paths used during measurement, including `get_planned_job_starts()`, `planned_at`, and `planned-starts-20261109`. Current names are `get_estimated_job_starts()`, `estimated_at`, and `estimated-starts/prediction-evaluation`.

Git retains committed source versions. Raw prediction evidence, source patches, profiler samples, and compiler-flags files are omitted. See [reproduction instructions](prediction-evaluation/README.md) to generate current measurements.
